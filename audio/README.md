# 음원 파일 넣는 곳

변조된 응원가 5개가 들어 있다. 교체할 때는 아래 이름 그대로 넣는다.

원본은 영상(mp4)으로 받아 ffmpeg로 오디오 트랙만 그대로 복사해 뽑았다.
재인코딩하지 않았으므로 음질 손실이 없다.

    ffmpeg -i "잘가세요.mp4" -vn -c:a copy -movflags +faststart 01-jalgaseyo.m4a

| 곡명 | 파일명 | 길이 |
|---|---|---|
| 잘가세요 | `01-jalgaseyo.m4a` | 31.6초 |
| 우리가 살아가는 동안 | `02-uriga.m4a` | 15.3초 |
| 홍하의 골짜기 | `03-hongha.m4a` | 16.5초 |
| 별이 되어 | `04-byeori.m4a` | 15.8초 |
| 끝까지 달린다 | `05-kkeutkkaji.m4a` | 15.9초 |

## 규칙

- **파일명은 정확히 위와 같아야 한다.** 한 글자라도 다르면 그 곡은
  데모음(전자음)으로 대체 재생된다.
- 프로그램은 앞 15초만 재생하고 자동으로 멈춘다.
- **설정 화면에서 재생 길이를 15초보다 늘리지 마라.** 잘가세요를 뺀 네 곡이
  15~16초짜리라, 그보다 길게 잡으면 곡이 끝난 뒤 무음이 흐른다.
- 파일이 없어도 프로그램은 멈추지 않고 데모음으로 돈다. 대신 화면에
  "데모 음원" 배지가 뜬다.

## 넣은 뒤 할 일

1. `sw.js`의 `CACHE_VERSION`을 한 단계 올린다 (`uhd-quiz-v6` → `uhd-quiz-v7`).
   올리지 않으면 이미 캐시된 태블릿에서 새 음원이 안 잡힌다.
2. 커밋하고 푸시한다.
3. 태블릿에서 페이지를 열고, 로고를 2초 길게 눌러 설정 화면의
   **음원 상태**가 5곡 모두 "정상"인지 확인한다.
4. 기내 모드를 켜고 한 판 돌려본다. "데모 음원" 배지 없이 진짜 음원이
   나오면 오프라인 준비가 끝난 것이다.

파일명을 바꾸거나 곡을 늘리려면 `js/songs.js`와 `sw.js`의 `AUDIO_PRECACHE`
두 곳을 같이 고쳐야 한다. 한쪽만 고치면 `npm test`가 잡아준다.
